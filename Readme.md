# Git Workflow Practice

This repository contains hands-on exercises I completed to strengthen my Git and GitHub skills, with a focus on workflows commonly used in technical documentation projects.

## Skills Practiced

- Creating and switching between branches
- Making and committing changes
- Merging branches and resolving changes
- Working with Markdown documentation
- Practicing collaborative editing scenarios
- Managing documentation updates through version control

## Repository Contents

The repository includes sample Markdown documentation, feature files, and collaborative editing exercises used to practice Git workflows.

## Purpose

As a Senior Technical Writer, I work with Git and Bitbucket in a docs-as-code environment. This repository provides a separate space to practice Git operations and experiment with version-controlled documentation workflows.

These are learning exercises rather than production documentation.
